>ESTAR → location, emotions, temporary states, ongoing actions. Estoy cansado. Está en Austin.
>Memory trick: DOCTOR (Description, Occupation, Characteristic, Time, Origin, Relationship) = SER
>Memory trick: PLACE (Position, Location, Action, Condition, Emotion) = ESTAR

► PRETÉRITO // USAGE ◄
>SER → completed identity. lightning struck. it ended. El evento fue un éxito.
>ESTAR → completed state, bounded period. Estuve en Austin tres días.
>stem SER: fu-    endings: e·iste·e·imos·isteis·eron    no accent marks
>stem ESTAR: estuv-    endings: e·iste·o·imos·isteis·ieron    these endings = ALL irregular preterites
>fui is also the preterite of ir (to go) — context always resolves the meaning

► IMPERFECTO // USAGE ◄
>SER → ongoing identity or trait over a period. De niño, era introvertido.
>ESTAR → prolonged condition or state. Siempre estaba cansado.
>imperfect = the backdrop. the weather during the whole trip. not the lightning strike.
>estar imperfect is fully regular: stem estab- + endings a·as·a·amos·ais·an

// adjectives that shift meaning with each verb
SER + adj = permanent nature
ser aburrido= boring (character)
ser listo= clever
ser malo= evil / bad person
ser bueno= good person
ser seguro= safe by design
ser rico= wealthy
ESTAR + adj = current condition
estar aburrido= bored (right now)
estar listo= ready
estar malo= sick
estar bueno= tasty / looks good
estar seguro= certain
estar rico= delicious
D·O·C·T·O·R six permanent reasons to use SER — what a doctor records on a permanent chart
P·L·A·C·E five transient reasons to use ESTAR — what is currently happening in a place
// common errors and warnings
ERR_01
tú preterite never ends in -s
fuiste ✓  ·  fuistes ✗     estuviste ✓  ·  estuvistes ✗
// English interference. Kill the -s instinct permanently.
ERR_02
nosotros ser preterite = fuimos, not fuemos
fuimos ✓  ·  fuemos ✗
// u carries through: fu → fui → fuimos
ERR_03
ellos ends in -ieron, never -on
fueron ✓  ·  fuieron ✗    estuvieron ✓  ·  estuvon ✗
// -ieron is the ending. always.
WARN_01
esta ≠ está
esta = this (adjective)  ·  está = is (verb)
// one accent mark. two different words. always write the accent.
WARN_02
era vs. es — tense boundary
es = is (present)  ·  era = was (imperfect)
// most common beginner slip. present vs. background past.
NOTE_01
fui = "was" AND "went"
ser + ir share identical preterite forms in all persons
// "fui al salón" = went  ·  "fui capitán" = was. context always resolves.
WARN_03
ser aburrido ≠ estar aburrido
ser aburrido = boring person (permanent)  ·  estar aburrido = bored (right now)
